# MUGLY — Frontend

Aplicación de una sola página (SPA) construida con:

- HTML5, CSS3 y JavaScript Vanilla (sin React, Angular ni Vue).
- Bootstrap, en copia local.
- Consumo de la API REST del backend (`backend/`).

Estado: pendiente de construcción. Las pantallas se definirán primero como
prototipos aprobados, a partir de los requisitos de MUGLY (MUGS.pdf, §13).
